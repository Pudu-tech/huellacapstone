# Plan de gestión de configuración de HuellApp

HuellApp · Pudú Tech · Borrador 0.1 · 27 de octubre de 2026

## Elementos controlados

Controlar código de frontend y backend, migraciones, documentos de alcance, pruebas, manuales, variables por ambiente y despliegues. Los datos de operación y secretos requieren control de acceso y no se incorporan al repositorio documental público.

## Versiones y revisión

El corte técnico de esta revisión es develop en d2b651f4270388cca337303a1b8adc03dbc891e1. Se propone que cada incremento y entrega identifique commit de componentes, historial de migraciones y URL de despliegue. La estrategia definitiva de ramas, PR, revisión y etiquetas debe ratificarse con el equipo; no se presume que una rama pública sea la entrega aprobada.

## Ambientes

Separar desarrollo, pruebas o preview y entrega. Registrar finalidad, responsable, datos permitidos y configuración. Un despliegue nuevo puede cambiar lo que se observa sin cambiar una URL de preview; conservar el identificador concreto probado.

## Documentación y cambios

Usar versión, fecha, responsable y estado de revisión. Mantener una única versión vigente por documento y conservar las históricas identificadas. Esta carpeta de borradores no reemplaza los originales oficiales. Word y Markdown se entregan alineados al mismo corte; si se modifica uno, debe actualizarse el otro antes de publicar.

## Auditoría de estado

Antes de una demostración, fijar versión y datos. Antes de entregar, conciliar requisitos, commits, migraciones, QA, manuales y acta. Revisar que no haya secretos ni información de terceros en capturas, logs o archivos exportados. La etiqueta de versión no equivale por sí sola a aprobación.
