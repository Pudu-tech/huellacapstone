## Evidencia del sistema

Para cada flujo conservar fecha, rol, datos saneados, pasos, resultado, capturas y commits de componentes. Para API registrar petición sin token visible y respuesta pertinente. Para base de datos usar estructura y consultas controladas sin exponer registros personales. Para reuniones conservar actas con acuerdos efectivos.

## Evidencia faltante o por consolidar

Quedan por registrar de forma trazable la validación de los flujos declarados probados, reglas y pruebas de ticket y seguimiento, recepción de correo, restauración, traspaso y conformidad. Las firmas y resultados de una reunión no se generan por anticipado.
